# Each dependency is bounded below the next major release after the one the tests were run with:
# a new major release is only installed once the tests pass with it and its bound is raised.
# The exact versions of a tested environment are in constraints.txt.

# transformers 5 cannot be used: its AutoTokenizer fails on the DrBERT models, whose tokenizer is a

# the text as transformers 4 does for almanach/camemberta-base
# (https://github.com/huggingface/transformers/issues/49622).
